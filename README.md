# Claude, one step at a time

A short path from "I use ChatGPT" to "I can hand Claude a real problem and check the result."

Four stages. Each stage is a few pages. Each page takes 10 to 45 minutes and ends with something you can see.

You do not need to know how to program. You do not need to read everything. Start at the top and stop whenever you like.
