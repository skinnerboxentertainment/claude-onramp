# 01 · Your first conversation

**Goal:** feel at home. **Time:** 15 minutes.

## Do this

1. Open the **Chat** tab. Type something real you would have asked ChatGPT today. Send it.
2. Reply once, in Spanish. Notice it answers in Spanish.
3. Click the **model name** next to the send button. You will see a list. Leave it on the default (Sonnet). Close it.

That is it. It is a chat. Everything you know from ChatGPT works here.

## What is the same, what is different

| You know | Here it is called | The one difference |
|---|---|---|
| GPTs | Projects | yours only, no store |
| Canvas | Artifacts | it can run as a real web page |
| Memory | Memory | you can read and edit every item |
| Custom instructions | Instructions for Claude | same idea |
| Deep research | Research | also looks in your connected Gmail or Drive |
| Temporary chat | Incognito chat (the ghost icon) | same |
| Codex | Claude Code | stage 2 |
| Image generation | nothing | Claude does not draw pictures |

Do not memorize this. Come back to it when a word confuses you.

## One habit to notice

Claude says "I don't know" when it does not know, and it will disagree with you when you are wrong. That is on purpose. Treat it as a colleague, not a search box.

## You are done when

You have had one useful conversation and you know where the model name is.
