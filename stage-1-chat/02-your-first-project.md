# 02 · Your first Project

**Goal:** a workspace for one piece of your real work. **Time:** 20 minutes.

A Project is a folder for conversations. It has its own instructions, its own files, and its own memory. If you used GPTs, this is that.

## Do this

1. In the left sidebar, click **Projects**, then **New project**. Name it after something you actually work on.
2. Open **Instructions** (sometimes shown as "Set project instructions"). Write three lines, in your own words. For example:
   ```
   You help me with the Saturday market website.
   Answer in Spanish unless I write in English.
   Keep answers short. Ask me before assuming.
   ```
3. Under **Project knowledge**, add two or three files that matter for this work: a document, a spreadsheet, a PDF. Up to 30 MB each.
4. Start a chat inside the project. Ask something only those files can answer.

## Try one more thing

Ask: *"Based on the files here, what am I probably forgetting?"* Read the answer critically. Sometimes it is wrong. Say so, and see what it does.

## You are done when

The project exists, has instructions, has files, and answered one question from them.
