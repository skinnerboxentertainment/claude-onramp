## What exists beyond this path

You do not need any of these yet. This is so the words are not scary when you meet them.

- **Cowork** (the middle tab). Claude Code for documents and spreadsheets instead of folders: same engine, no folder to choose. Try it when a task is about a document rather than files.
- **Connectors**. Let Claude read your Gmail, Drive, Calendar, or Slack. Settings > Connectors. Useful, and worth deciding carefully.
- **Research**. In Chat, for questions that need many sources. Slower, with citations.
- **Claude in Chrome**. Claude drives your browser. Fill forms, compare sites. Paid plans.
- **Subagents, hooks, MCP, worktrees**. Tools for people running many Claude sessions on large software projects. Not for you today. If a task ever needs one, Claude will tell you, and you will already know how to ask it to explain.

## If you want a target

Anthropic runs a certification called **Claude Certified Associate: Foundations** (about $99, two hours, online). It tests using Claude well: prompting, projects, connectors, judging outputs. Everything in stages 1 to 3 is on it. Not required. Some people like a finish line.
