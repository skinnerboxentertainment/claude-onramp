# 15 · Write it down first

**Goal:** handle a big task by writing one page before Claude touches anything. **Time:** 30 minutes.

Stage 4 is optional. Come here when a task is bigger than an afternoon, or when you find yourself typing the same request every week.

## The one page

For anything Big (page 13), write a file called `SPEC.md` in the folder before you start. Five headings, a few lines each:

```
# What I want
One paragraph, in plain words. Who it is for. Why.

# What "done" looks like
The check. What I will open and compare at the end.

# What is involved
The files or folders it will touch. The ones it must not touch.

# Out of scope
The things it should NOT do, even if they seem helpful.

# Pieces
1. First piece, finishable in one session, with its own check.
2. Second piece.
3. ...
```

You can ask Claude to draft it: *"Interview me, then write SPEC.md using these five headings."* Then edit it yourself. The editing is where the thinking happens.

## Then, each session

Open the folder. Mode Plan. Send: *"Read SPEC.md. Plan piece 1 only."* Run the loop. When piece 1 passes its check, tick it off in `SPEC.md` and stop for the day.

## Why a file and not a message

A message disappears when the conversation gets full. A file is there tomorrow, and in the next session, and for whoever helps you next. Claude reads it before it reads anything else.

## Do this

Take the Big task you labeled on page 13. Write its `SPEC.md`. Do piece 1.

## You are done when

`SPEC.md` exists and piece 1 is ticked.
