# 17 · Put it on a schedule

**Goal:** know that a repeated command can run by itself, and set one up if you want it. **Time:** 15 minutes.

## When this is worth it

Only when all three are true:

1. You have run the command by hand at least three times and it was right every time.
2. It has a check built in (page 12).
3. Being wrong once would be annoying, not damaging.

If any of the three is false, keep running it by hand. Automation of something you do not yet trust just makes mistakes faster.

## Do this

The desktop app can run a Code session on a timer: every morning, every Monday, whatever you choose. The steps live on the official page, which changes as the app changes, so follow it rather than a copy here:

- [Schedule recurring tasks in Claude Code Desktop](https://code.claude.com/docs/en/desktop-scheduled-tasks) (English)
- [La misma página en español](https://code.claude.com/docs/es/desktop-scheduled-tasks)

A good first schedule: `/inventory` on your Downloads copy every Monday at 9:00, writing the file and nothing else.

## Two things to know

- A scheduled task runs with the permission mode you give it. Give it the narrowest one that works. It should never need Auto.
- Look at the result the first three times it runs. Then relax.

## You are done when

Either a task is scheduled, or you decided honestly that nothing you do yet meets the three conditions. Both are correct.
