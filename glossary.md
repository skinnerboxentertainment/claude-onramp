# Glossary

Only look here when a word bothers you.

- **Artifact.** A result Claude shows in a side panel: a page, a chart, a document. It can run as a real web page.
- **Auto mode.** Claude acts without asking, while a separate checker blocks risky actions. Not for your first weeks.
- **CLAUDE.md.** A short text file at the top of a folder. Claude reads it first, every time.
- **Claude Code.** The Code tab. Claude with access to the files in one folder you choose.
- **Context.** Everything Claude is holding in mind in this conversation. It fills up. When it is full, start a new session.
- **Cowork.** The middle tab. Claude Code for documents rather than folders.
- **Connector.** Permission for Claude to read one of your services, like Gmail or Drive.
- **Diff.** The exact lines that changed, old beside new. Click the +12 -1 counter.
- **Effort.** How hard Claude thinks. Low, Medium, High, Extra high, Max. Higher costs more of your plan.
- **Memory.** Small notes Claude keeps about you between conversations. Settings > Memory.
- **Model.** Which version of Claude answers. Sonnet for everyday, Opus for hard things.
- **Plan mode.** Claude can only look and propose. Nothing changes.
- **Project.** A workspace in Chat with its own instructions, files, and memory.
- **Session.** One conversation in the Code tab, tied to one folder.
- **Skill.** A saved command. Type `/name` and Claude runs the saved request.
- **Spec.** A one-page plan you write before a big task. Your convention, not Claude's.
- **Usage.** How much of your weekly plan you have spent. The ring next to the model name.
