# 07 · Undo it

**Goal:** lose the fear. **Time:** 10 minutes.

Nothing Claude does is final if you set things up right. This page proves it.

## Do this

1. Still in the `claude-test` session, mode **Manual**, send:
   ```
   Put every file back to its original name. Show me the table first, then do it.
   ```
2. Accept the changes. Check the folder. Original names are back.
3. Now do it the other way. Send the rename request from page 06 again. When Claude asks permission for the first file, click **Reject** instead. Tell it: *"Actually, only rename the ones that are receipts or invoices."* Watch it adapt.
4. Click the **+12 -1** style counter (or press **Ctrl+Shift+D**). This is the diff view. Everything Claude changed, side by side. Get used to opening it.

## Three ways to undo, from safest to last resort

1. **Reject** before it happens. That is what Manual mode is for.
2. **Ask Claude to reverse it.** It remembers what it did in this session.
3. **Delete the copy and copy again.** This is why rule 1 exists.

## A habit to build now

Before you say yes to anything, read the proposal. Not the whole file. Just the line that says what will change. If you cannot explain in one sentence what is about to happen, do not click accept. Ask.

## You are done when

You have rejected one change and reversed one change on purpose.
