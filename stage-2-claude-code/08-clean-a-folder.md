# 08 · Clean a messy folder

**Goal:** a multi-step job, with a dry run first. **Time:** 20 minutes.

## Prepare

Use the fake folder that comes with this path: `exercises/messy-downloads`. It has 40 files with terrible names. Copy that folder to your Desktop first (rule 1). Or use a copy of your real Downloads, if you feel brave.

## Do this

1. Code tab, **Select folder**, pick the copy. Mode: **Plan**.
2. Send:
   ```
   This folder is a mess. Propose a way to organize it into subfolders by type of file. Show me a table of every file and where it would go. Do not move anything yet.
   ```
3. Read the plan. Push back on anything. For example: *"Put the CSV files together with the spreadsheets"* or *"Anything ending in .exe goes in a folder called Installers."*
4. Switch to **Manual**. Send: *"Do it."* Accept the moves.
5. Now ask for something new:
   ```
   Write a file called INVENTORY.md with a table of every file: name, folder, size, date modified, and a one-line guess at what it is.
   ```
6. Open `INVENTORY.md` (click its name in the chat, or open it in Explorer). Spot-check three rows against the real files.

## Notice

The dry run cost you two minutes and gave you a plan you could argue with. That pattern, propose then do, is the single most useful habit in this whole path. Stage 3 is entirely about it.

## If it goes wrong

Ask it to put everything back in the top folder. Then start again with a clearer plan request.

## You are done when

The folder is organized and `INVENTORY.md` exists and is roughly right.
