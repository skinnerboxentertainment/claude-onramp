# Exercise files

Everything here is fake. Break it freely. **Copy a folder to your Desktop before opening it in the Code tab**, so the originals stay clean for next time.

| Folder | Used on | What is in it |
|---|---|---|
| `notes/` | page 09 | nine short notes about a small website project, with two deliberate contradictions (the deadline moves, the rule about prices changes) |
| `messy-downloads/` | page 08 | forty files with bad names and mixed types |
| `receipts/` | page 12 | twelve fake receipts as PDFs, useless file names, vendor, date and total inside |

Screenshots for page 06 are not included. Use ten of your own; they are more fun.

To regenerate everything from scratch (for example after an exercise), run `python tools/make_samples.py` from the top of this repo, or just ask Claude Code to do it.
