# Cheatsheet

One page. Print it.

## The three rules
1. Work on a copy.
2. One folder at a time.
3. Plan first.

## The loop
Say the goal → Plan mode → read the plan → approve (Manual) → check the result yourself → keep or undo.

## Modes (selector next to the send button)
| Mode | Claude can |
|---|---|
| Plan | look and propose only |
| Manual | change things, asking you each time |
| Accept edits | change files without asking, still asks before running commands |
| Auto | most things, with a safety check in the background |

## Keys in the desktop app (Windows)
| Key | Does |
|---|---|
| Esc | stop now |
| Ctrl+N | new session |
| Ctrl+Shift+M | mode menu |
| Ctrl+Shift+D | show what changed |
| Ctrl+/ | all shortcuts |
| `/btw` question | ask on the side |
| `/init` | draft CLAUDE.md |
| `/help` | list commands |
| `@filename` | point Claude at a file |

## Prompt endings that build in a check
- "...then re-open three at random and confirm."
- "...then count the files and tell me if the number changed."
- "...show me the table before changing anything."
- "Interview me first, one question at a time."

## Three habits from stage 1
Say why, not just what. Documents first, question last. Effort setting instead of "think step by step".

## Five mistakes to avoid
Three jobs in one session · correcting the same thing three times · a long CLAUDE.md · trusting "done" · "look into this" with no end.

## When stuck
Esc · new session with a better request · `/btw` · check the usage ring · "undo everything from the last request".
